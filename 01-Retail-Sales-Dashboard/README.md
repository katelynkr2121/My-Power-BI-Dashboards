#  Retail Sales Dashboard | Power BI


##  Project Overview

The Retail Sales Dashboard is an interactive data visualization project developed using Microsoft Power BI. The dashboard provides insights into retail sales performance, customer behavior, and order operations through three analytical report pages.

The main objective of this project is to transform retail data into meaningful visual insights that support better understanding of business performance.

##  Project Objectives

- Analyze overall retail sales performance.
- Understand customer purchasing behavior.
- Explore order-related activities and operations.
- Identify meaningful patterns and trends from the dataset.
- Present business information through interactive visualizations.

## 📊 Dashboard Pages


### 1. Sales Overview
This page provides an overall view of retail sales performance.

Key Focus:
- Overall sales performance
- Important business metrics
- Sales trends and patterns
- Overview of business performance

### 2. Customer Analysis
This page focuses on analyzing customer-related information and purchasing behavior.

Key Focus:
- Customer analysis
- Customer purchasing patterns
- Customer-related sales insights
- Understanding customer behavior

### 3. Orders & Operations
This page provides insights into order-related information and operational activities.

Key Focus:
- Order analysis
- Order-related performance
- Operational insights
- Understanding order activities
